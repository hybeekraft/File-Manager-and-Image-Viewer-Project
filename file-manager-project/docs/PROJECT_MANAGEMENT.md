# Project Management Practice

Use the same product backlog in each platform, but learn the strengths of each one.

## Epic 1 — Project foundation

Stories:
- Create repository
- Define branch strategy
- Configure frontend
- Configure backend
- Configure PostgreSQL
- Write project README

## Epic 2 — File management

Stories:
- Upload a file
- Validate file types
- List files
- Search files
- Download files
- Delete files

## Epic 3 — Image viewer

Stories:
- Show image thumbnails
- Open image viewer
- Zoom image
- Close viewer

## Epic 4 — Quality

Stories:
- Add API tests
- Add frontend build validation
- Configure GitHub Actions
- Configure Azure pipeline
- Document deployment

## Suggested Jira workflow

Backlog → Selected for Development → In Progress → Code Review → Testing → Done

## Suggested Trello columns

Backlog | Ready | Doing | Review | Done

## Suggested Asana sections

Product Setup | Core Files | Image Viewer | QA | DevOps

## GitHub

Use issues for individual tasks and pull requests for completed work.

## GitLab

Mirror the repository and compare the GitLab workflow with GitHub.
